# EMS production readiness

**Production promotion is blocked.** The verified candidate runs on the local fixture backend. The current cluster inventory has no confirmed EMS workload, release mapping, or ingress. Local Docker returned a socket permission error. The Compose file passed configuration parsing. An isolated PostgreSQL 18.6 process and compiled Node build exercised the native flows without containers.

## Recorded verification

The final run passed 106 Vitest tests, one Chromium end-to-end test, targeted ESLint, TypeScript, the Lovable and Node builds, and the edge service/player build. A new native database applied all four migration checksums and a second run applied zero changes.

- Node factory acceptance exercised two sites with saved layout, hardware records and routes, direct cross-site denial, origin denial, and a concurrent revision conflict. Two authored apps remained distinct. A separate fixture reviewer approved and published an immutable Ed25519 package. Tampered content and cross-site package retrieval failed.
- The assignment HTTP acceptance exercised anonymous and restricted-scoped denial, concurrent overlap prevention, and deterministic terminal resolution. The provisioned isolated edge runtime staged and activated the released package and returned signed exact device readback. It served the matching Studio renderer in the kiosk. The final run recorded release `05fb65c5-0ee8-48f8-824e-71c20d5f1f19`, assignment `8df0b391-7999-48f3-9882-218d78022e6b`, and active digest `dd83eac57a1e2331845d8753fb1f41dd59bd765f69fb064a421887fe34856094`.
- Browser verification used Chromium WebGL2 and desktop/mobile checks through the native preview. Plan, elevation and inspector stayed synchronized during a snapped 3D gizmo movement, undo and save. Context loss left the 2D alternatives usable and Retry restored the renderer. The Studio saved and validated a two-screen HMI and completed its portrait preview.
- A PostgreSQL 18.6 restore into a fresh isolated cluster preserved workspace revisions, a signed release, assignments, the migration ledger and audit. The legacy sandbox fixture retained its historical revision across migration 0002 → 0003 and refused direct draft/outbox inserts and sandbox release.
- The acknowledgement fixture tested sender separation, age, digest mismatch, forced rollback between inbox and status writes, concurrent duplicate recovery, exhaustion recovery and separate delivery/adoption state. No outbound requests were made.
- The Admin QA page rendered in an authenticated local browser session. Its API denied anonymous and cross-site requests. It reported pending production adoption, commissioning and environment evidence explicitly.
